# Security

Please report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/kleash/crate/security/advisories/new), not in a public
issue.

Crate's releases are signed with a Developer ID and notarized by Apple: `spctl -a -vv /Applications/Crate.app` should
say `source=Notarized Developer ID` and `origin=Developer ID Application: Shubham Aggarwal (PPWGP2KY2M)`. Each release
lists its zip's SHA-256, and published releases can't be changed.
